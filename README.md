# RepoFix-RL

面向小型 Python 仓库的可评测代码修复 Agent 项目。完整项目计划见 [`docs/项目书与任务拆分.md`](docs/项目书与任务拆分.md)。

## 项目结构

- `frontend/`：交互式演示前端
- `backend/`：Agent 运行时、工具与 API
- `training/`：SFT/GRPO 训练代码与配置
- `data/`：任务定义、数据说明与划分（大文件不入 Git）
- `experiments/`：实验记录和结果摘要
- `scripts/`：开发、评测和训练辅助脚本
- `docs/`：项目书、设计和复现说明

## 当前状态

项目规划阶段。代码骨架和首个可运行里程碑将按项目计划逐步补齐。
